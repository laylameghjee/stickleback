# Population Genetic Structure across ChrI Inversion in Stickleback #


## Project Overview 
This project investigates population genetic structure across a 500kb chromosome I (chrI) candidate inversion region in 906 globally distributed Gasterosteus aculeatus (threespine stickleback) individuals. The study examines how broad geographic history, freshwater-marine ecological divergence and fine scale genomic architecture contribute to patterns of genetic variation within this region.  

Whole region principal component analysis (PCA) is used to characterise the dominant axes if genetic differentiation and their relationship with Atlantic-Pacific divergence and finer scale geographic classification. Sliding window PCA is then used to determine whether specific genomic sections depart from the overall pattern. Ecological classificaiton and fine scale gene annotation are subsequently incorporated to investigate the biological context of local genomic heterogeneity. 

By intergreating geography, ecology, and genomic position this project treats the ChrI candidate inversion not simply as an ecological marker but as a structured genomic region in which population history, ecological divergence, and inversion associated genomic architecture interact to shape the observed genetic variation.
